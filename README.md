> **XMU Nav** 是一个专为厦门大学师生打造的轻量级、响应式纯静态校园导航与资源聚合站点。无需安装任何后端依赖，聚合校内常用教务系统、科研平台、学习资源与日常工具，即开即用。

## ✨ 核心能力与特色亮点

- 🧭 **全景式校园服务聚合**：系统化归类本科生与研究生教务系统、选课系统、财务与资产处、学工系统、校园卡充值等核心入口。
- 📚 **科研与学术资源集成**：快速直达厦大图书馆、中文外文数据库、知网、Web of Science、Overleaf 等科研常用站点。
- 🔍 **多引擎一键搜索**：内置聚合搜索栏，支持在百度、必应、Google、知乎及校内站内一键切换检索。
- 📱 **纯静态与极致轻量**：纯原生 HTML5 / CSS3 / JavaScript 构建，无任何后端依赖与数据库开销，秒级瞬时加载。
- 🎨 **响应式布局与主题适配**：适配桌面端宽屏与移动端手机竖屏浏览，具备舒适的现代化排版交互与视觉反馈。
- 🔗 **研究生毕业指引联动**：无缝链接专用的研究生毕业全流程指引系统（[xmu-grad-guide](https://bug423.github.io/xmu-grad-guide/)），为毕业生保驾护航。

## 🛠️ 本地运行指南

本项目为纯静态工程，无需安装任何构建工具或复杂的编译流程，支持任何静态 Web 服务器即开即览：

### 快速预览（Python 3 内置服务器）

```bash
# 在项目根目录下执行
python3 -m http.server 8000
```

打开浏览器访问 [http://localhost:8000](http://localhost:8000) 即可开始浏览。

### 其它可选静态托管方式

```bash
# 使用 Node.js 的 serve 工具
npx serve .

# 或直接使用 VSCode 插件 Live Server 打开 index.html
```
